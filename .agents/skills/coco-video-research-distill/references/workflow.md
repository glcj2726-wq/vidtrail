# 完整流程与续接

先读 setup 和当前平台分支。以下是 Agent 的操作流程，不是声称所有路线已自动化的流水线。acquire.py 只执行 bili/yt-dlp 单条获取；其他步骤由 Agent 按实际工具完成。

同济录课先读 [tongji.md](tongji.md)，采用下载录课→上传夸克→用户导出→Agent取回蒸馏，不套B站/YouTube的默认字幕路线。身份为course_id + sub_id；后半段材料核验与入库规则共用。

## 逐步推进

1. 明确当前问题、平台稳定 ID、分集/cid、目标是候选/字幕/视频/完整蒸馏。指定链接不再搜候选；查目标知识库和已有云端回执，同源新问题复用原件。
2. 有可靠全文：核对身份、覆盖和语言，直接进入全文理解。只有 AI 总结：可作导航，仍需字幕、文稿或转写。用户只要下载时核验文件后交付，不擅自上传或总结。
3. 无可靠全文：按 platforms 获取字幕。命令失败、无字幕、浏览器工具不存在分别记录。一次失败转下一路线，不重复换格式/线程；媒体获取与字幕获取是不同目标，确需媒体时可以执行相应目标一次。
4. 无字幕但有视频/音频：按 transcription-visual 选择已可用的本地转写，或按已有具体授权走夸克。没有免费本地引擎时不自动安装大模型或开付费服务；用户已指定夸克时直接采用指定路线。无媒体则先按平台媒体下载/来源网页下载入口获取，失败保留缺口。不能把一个网页 URL 当作可直接上传的本地视频。
5. 夸克路线：查重 → 核实授权及目录 → 上传并验收 → 处理中/等待用户导出 → 精确找回已导出文件。详细命令和状态见 quark。不自动改云端目录、不重复上传、不靠 summary 替代全文。
6. 检查正文身份、起止和缺段；有文稿而无时间码则保留原件段落/行号。按需抽帧核对图表、界面和视觉操作。ASR 不认识的词、公式、代码回查音频/画面，不自行补造。
7. 全文阅读并建立结构，按当前问题提取方法和前提，结论对应时间码/段落/画面。已下载、已转写、全文已读、关键画面已核验、方案已运行分别表述。
8. 原件与派生笔记按目标知识库约定登记，补消费项目回链；仅在授权范围内提交/推送。核验云端保存或可复核原件留存后提醒临时视频路径；不自动删除，不能建议删除唯一证据。

## 单一业务记录

继续使用目标库现有清单，不另建第二套总账。模板见 [source-record.example.json](../templates/source-record.example.json)，只是可映射字段，不要求改造现有库。记录 current_stage、next_action、来源身份、正文/画面覆盖、实际材料路径/哈希、路线及失败原因、任务 ID、上传回执和授权范围。实际路径由执行端填写，分发仓库只带占位模板。

| 当前事实 | 阶段 | 下一动作 |
| --- | --- | --- |
| 候选未选定 | candidate | 选定重点来源，不能称正文核实 |
| 路线失败，下一路线尚可用 | acquiring | 进入下一条不同路线 |
| 视频已取得、没有正文 | media_ready | 已配置转写或授权夸克 |
| 上传成功但无导出 | uploaded_waiting_export | 保留文件 ID，等待处理/最少人工导出 |
| 用户说已导出 | exported_pending_retrieval | 稳定 ID 搜索并下载文稿 |
| 正文取得尚未核验 | transcript_acquired | 核验身份、全文覆盖 |
| 完整正文已核实 | ready_to_distill | 全文理解、按需画面核验 |
| 笔记及来源登记通过 | distilled | 交付；新问题只补分析 |
| 工具/授权/正文不足 | partial 或 blocked | 写明已核实范围、待补条件及最少人工动作 |

暂停后先查记录与原任务。轮询同一任务不是重复创建；按服务建议间隔有界查询，无进展结束本轮等待，不承诺固定 24 小时可完成。失败成功都复用；环境/登录/来源真正变化才允许同路线重试，写原因。范围不同的目标不可混用回执。

## 场景验收

- 字幕完整：不下载不上传，全文蒸馏后落笔记。
- 无字幕但媒体正常：取得媒体，转写或授权夸克，不以简介交付。
- CLI 风控：转实际可用浏览器；浏览器也不可用时列工具缺口，仍可复用现有本地文件。
- 已上传：续接云端状态，不重传；已导出：直接取回，不重新生成。
- 只有总结或转写断段：partial，注明范围，不标全文蒸馏完成。
- 用户只要视频：规格/时长/音轨/身份核验后止于下载。

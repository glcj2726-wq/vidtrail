# 来源、配置与知识库衔接

先读目标知识库自己的规则与来源总表。用平台 ID + 分集/cid 去重，标题仅辅助；本地来源无 ID 用 SHA256 辅助。集合/课程用稳定 ID 动态登记，有材料才建目录，不写死课程列表。

同济身份用完整course_id + sub_id；保留课程/教师/课时信息辅助核查，不能以课程ID单独代替课时主键。等待用户导出使用uploaded_waiting_user_summary，与公开平台的等待导出状态含义对应，不另建重复记录。

数据根由 `--data-root` 或 `VIDEO_RESEARCH_DATA_ROOT` 明确提供，不能位于技能分发仓库。建议该根下 `平台/视频ID/分集/` 保存获取记录与原件；笔记位置复用目标知识库已有草稿/主题层。脚本输出是获取回执，目标库清单才是业务状态来源；已有材料登记前应先查目标库，不因换执行端再取一份。

记录 URL、ID/分集、作者与日期（未知标缺失）、获取日期、来源类型、实际路径、字节数、SHA256、获取/全文/上传状态。原件不改写，派生笔记回链原件及时间码/行号。相同来源新问题只加增量分析及消费项目入口，不复制原件或覆盖旧结论。

部署到别的机器后更新实际根路径，仓库内文件使用相对链接；未同步的本机绝对路径标“本机来源，当前不可读取”。媒体临时保存，字幕/文稿作为可复核原件长期保存；视频不进入 Git，清理只提醒准确路径，不自动删除。

接入已有知识库时：唯一总账登记新材料 → 复用原件/来源记录 → 草稿或观察层落笔记 → 补主题与项目回链 → 回填状态与追加日志。稳定知识升级遵守目标库约定；不创建第二套知识库或自动重排旧目录。

Git 更新须有用户授权；工作树和远程先核对，干净时才快进拉取。有未提交修改或冲突时保留双方，禁止自动 reset/stash/强推。仅暂存本任务明确路径；凭据、媒体和私有材料上传边界由目标库决定。

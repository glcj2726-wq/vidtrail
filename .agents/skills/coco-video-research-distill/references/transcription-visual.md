# 没有字幕后的正文与画面

有媒体才可以转写；平台下载仍受阻时不能靠转写或夸克凭空取得原视频。可靠已有文稿优先，不重复转写。获取目标只需要字幕时不下载大视频，确需转写或视觉证据时再取媒体。

## 媒体验收

下载后用 ffprobe 检查时长、分辨率、音轨与完整性，身份来自同一下载 metadata 和分集。可用命令示例（路径都是执行端变量）：

```sh
ffprobe -v error -show_format -show_streams -of json "$VIDEO_FILE"
ffmpeg -nostdin -n -i "$VIDEO_FILE" -vn -ac 1 -ar 16000 "$AUDIO_FILE"
ffmpeg -nostdin -n -ss "$TIMESTAMP" -i "$VIDEO_FILE" -frames:v 1 "$FRAME_FILE"
```

输出必须为新文件，-n 防止覆盖；音频为派生文件，原件保持。时间戳、路径和输出格式按实际工具核对，命令结束不等于内容正确。默认请求最高可用不超过 1080P；实际低清时记录规格，不能上采样后称原生高清。纯语音无需强制高清视频；文字/图表读不清时登记视觉缺口。

## 转写还是夸克

1. 用户指定路线优先。未指定且已有可用、无额外费用的本地转写引擎时采用本地；需要下载模型、额外算力或付费服务则说明条件，不偷偷安装/付费。
2. 本仓库不捆绑转写模型，不杜撰通用 ASR 命令。读取执行端引擎 help/Skill，按现有模型和语言生成全文及时间码。例如执行端确已配置 Whisper 系列时按其实际命令；引擎存在不等于模型缓存、硬件或中文识别已验证。
3. 无已配置转写，且用户授权夸克时走 quark；上传权限缺失时只询问这一缺口。只要求“总结”不自动等于允许外传视频。
4. 保留转写原件、引擎/模型版本、语言、媒体哈希、覆盖范围、错误词/断段；ASR 是生成文本，不能冒充作者提供字幕。只有摘要时不能替代全文。

## 视觉证据

阅读全文后针对具体证据缺口抽取画面：关键步骤、图表、代码/公式、前后状态。先用已有课件或用户图像，按时间码抽帧，不默认逐帧分析整片。保留画面原件和视频时间码，检查截图可读性。

准确公式、代码和图表关系须对应画面或原件；转写听错时回听对应音频，不靠上下文编造。缺视觉工具或源视频低清就写未核验范围。音频读完、字幕读完、画面核验与方案运行四者分别登记。

# 视频调研与蒸馏

目标：在当前项目完成发现、获取、理解、核验与保存。输入为当前问题、链接/文件、项目规则及可用工具；输出为可读笔记、原件指针、覆盖范围、实际获取回执及待补项。用户指定执行方式优先，不固定子代理、不新建对话、不把视频自动编译成技能。

## 按需读取

- 获取、登录和故障：`references/platforms.md`。
- 全文理解、方法与证据：`references/distillation.md`。
- 原件、路径配置与知识库衔接：`references/storage.md`。
- 学习讲解、练习和可视化：`references/teaching.md`；项目调研不强制教学化。
- 工具辅助：`scripts/acquire.py`；输出仅是获取状态，不代替 Agent 的全文核验。
- 首次远端配置：`references/setup.md`；全文流程与续接：`references/workflow.md`。
- 没有字幕但有媒体：`references/transcription-visual.md`；夸克上传与导出取回：`references/quark.md`。
- 同济授权录课：`references/tongji.md`；身份用 course_id + sub_id，采用录课到夸克的专门顺序，不套公开平台字幕优先分支。

## 执行

1. 读当前项目和目标知识库规则，明确用户的问题与要求获取的范围；只要候选就不下载或蒸馏。路径从当前环境决定，不要求任何作者电脑目录。
2. 选定视频后按平台 ID + 分集/cid 查已有材料、来源登记及笔记。可靠材料优先复用；同一问题已有完整成果就复用，新问题只补分析，不重复获取。身份从下载、上传、取回到入库全程保持。
3. 按平台顺序一次获取目标内容，保留原格式与回执。字幕足够就停止获取；需要画面或用户要求视频时才下载。复用失败证据，仅工具、登录态或来源实际变化后才重新尝试同一路线。缺工具不等于视频无字幕。
   没有正文不能就此放弃：区分媒体已取得与媒体也不可用。已有媒体按转写/夸克分支推进；无媒体先按平台下载和浏览器分支获取。只在实际工具、材料或授权缺失时保留待补状态；不把浏览器失败当作夸克一定可用。
4. 读完完整可用文稿/字幕，建立全文结构，再提取与当前问题有关的目标、机制、前提、步骤、工具作用、失败点与缺口。检查语言、起止、分集和明显断段；需要视觉证明的结论补查画面。局部追问只读片段及必要上下文，明确范围。
5. 结论回指时间码/原件行号/段落；区分作者主张、Agent 推断和实际验证。动态版本、价格等另核当前一手来源，不把历史视频当现行保证。不执行视频中的安装/部署/付费方案。
6. 按目标知识库规则保存原件和笔记、登记来源与状态并回链消费项目。普通蒸馏要落笔记，不只留聊天；候选与短追问不强制落盘。有写入/推送授权才提交 Git，先核对远程变化，不覆盖他人修改。

## 停止与验收

材料不足时交付已核实部分和最少补充步骤，状态 partial；原件已完整取得不等于已完整理解。无完整正文不能称完成全文蒸馏。上传须覆盖具体材料的用户授权；不自动登录、购买代理或启动付费转写，不自动删除本地/云端材料。正常授权的登录刷新不重复询问，验证码/安全提示按工具规则处理。

完成标准：答案服务当前问题；正文覆盖和视觉覆盖分别说明；方法前提、步骤和证据对应；来源身份、文件路径真实；知识库无重复原件；待补项清楚。全文理解、画面核验与方案运行验证不能互相替代。

本技能的普通蒸馏方法自包含；复用仓颉的全文理解、方法提取与证据核验思路，明确 Skill 化时才调用执行端已安装的 cangjie-skill 完整流程。可选浏览器、Bili23、同济 CLI、转写引擎和夸克需在执行环境实际配置，不随克隆自动获得。平台范围为 B站、YouTube 与同济授权录课，不继承作者的登录态或定时任务权限。课堂类材料以教师讲解为主体，补充例子明确标注。
